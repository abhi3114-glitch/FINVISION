Next.js Finance Dashboard Starter
================================

What's included:
- Next.js app (pages/router) ready
- TailwindCSS configured
- Framer Motion included for animations
- Recharts placeholder chart components
- Simple layout (Sidebar + Header + Dashboard cards)
- Environment variable: NEXT_PUBLIC_API_URL to point to your Flask backend

Quick start:
1. unzip and cd into project
2. npm install
3. npm run dev
4. open http://localhost:3000

To deploy on Vercel:
- Push to GitHub and import project in Vercel (it auto-detects Next.js)
- Set environment variable NEXT_PUBLIC_API_URL to your backend URL (e.g., http://127.0.0.1:5000/api or deployed URL)
